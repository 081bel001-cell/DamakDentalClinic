# Damak Dental Clinic (Dental Cleaning Landing Site)

Static site (HTML/CSS/JS).

## Deploy (Cloudflare Pages)
1. Push this repo to GitHub.
2. In Cloudflare Dashboard: Workers & Pages -> Create application -> Pages -> Connect to Git.
3. Framework preset: None
4. Build command: (empty)
5. Output directory: /

## Configure
- Update business info in `assets/js/clinic.config.js`.
- Update domain in `sitemap.xml` and `robots.txt` once you have the final URL.
